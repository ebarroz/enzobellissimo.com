{%- comment -%} post-date.html — a long date in the page's language. {% include post-date.html date=page.date lang=page.lang %} Liquid's `date` filter only speaks English, so the month comes from the string table and `date_long` decides the order ("August 25, 2026" vs "25 de agosto de 2026").
