{%- comment -%} =========================================================================== lang-switch.html — the language control in the header. Rendered as a segmented pill with a globe, not as two more nav links: the first version sat bare next to "RSS" and read as navigation, which is exactly the thing a language control must not do. The current language is filled, so state is visible without reading the labels. Each option links to the *same page* in the other language, resolved through the `ref` key shared by a translation pair. With no counterpart it falls back to that language's home — a missing translation is never a dead end. Requires the variables set by i18n.html. =========================================================================== {%- endcomment -%} {%- for code in site.languages -%} {%- assign l = site.data.i18n[code] -%} {%- if code == lang -%} {{ l.name }} — {{ l.short }} {%- else -%} {%- assign target = l.home -%} {%- if page.ref -%} {%- assign twin = all_docs | where: "ref", page.ref | where: "lang", code | first -%} {%- if twin -%}{%- assign target = twin.url -%}{%- endif -%} {%- endif -%} {{ l.short }} {%- endif -%} {%- endfor -%}
